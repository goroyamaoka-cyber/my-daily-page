営業パーソンのためのAI活用完全ガイド｜ChatGPT・Claude・Geminiを商談・提案・顧客分析に使う実践法【2026年版】

#営業AI活用#ChatGPT営業#Claude営業#AIプロンプト#提案書AI#BtoB営業#AI仕事術#生成AI活用

「AIを使っている営業」と「使っていない営業」の差が開いている

2026年現在、生成AIを業務に活用している営業パーソンと、そうでない営業パーソンの間には、準備の質・提案書の完成度・情報収集のスピードで明確な差が生まれています。

しかし「AIを使う」といっても、「なんとなくChatGPTで文章を書かせている」だけでは、本当の意味でのAI活用とは言えません。どの場面でどのAIをどう使うか——この設計が、営業AIの本当の価値を決めます。

本記事では、営業活動の各フェーズ別に、実際のプロンプト例と使い分けを解説します。

営業AIの基本：3つのAIの特性と使い分け

AI最大の強み営業での主な用途注意点
ChatGPT（GPT-4o）汎用性・使いやすさ・プラグイン連携メール文章・アイデア出し・トーク台本最新情報は弱い（Web検索機能を使う）
Claude（claude.ai）長文の理解・論理的な文章生成・誠実な表現提案書・議事録要約・複雑な資料の分析画像の操作は限定的
Gemini（Google）最新情報・Google連携・リアルタイム検索顧客企業のニュース調査・業界動向把握日本語の細かいニュアンスはやや弱い

使い分けの基本方針： 最新情報の収集はGemini、長文の提案書や議事録はClaude、メール・トーク台本はChatGPT——と目的別に使い分けることで、それぞれの強みを最大化できます。

フェーズ①：商談前の準備（所要時間：30分→5分）

商談前の準備は、AIが最も劇的に時間を短縮してくれるフェーズです。

顧客企業のリサーチ（Gemini推奨）

従来：ニュース検索・IR資料確認・Linkedin調査で30〜60分
AI活用後：5〜10分

プロンプト例（Gemini）：

「以下の情報を教えてください。
企業名：[顧客企業名]

1. 直近3ヶ月の主要なニュース・プレスリリース
2. 主力事業・製品・競合との差別化ポイント
3. 業界全体の現在の課題・トレンド
4. この企業が抱えていそうな経営課題（仮説）
5. 私が提案できる切り口のヒント

私は[自社サービス]の営業担当です。」

商談の仮説・質問リスト作成（Claude推奨）

プロンプト例（Claude）：

「私はBtoB営業担当です。
明日、[顧客企業名]の[部署名]の[役職]の方と初回商談があります。

【企業情報】
・業種：[製造業など]
・最近のニュース：[調べた内容を貼り付け]
・提案したいサービス：[自社サービス名]

以下を作成してください。
1. この企業が抱えていそうな課題の仮説（3つ）
2. 仮説を検証するためのヒアリング質問（各5問）
3. 商談の導入で使える自然な話題（2つ）
4. この商談での理想のゴール」

フェーズ②：提案書・見積書作成（所要時間：2日→3時間）

提案書作成は最も時間がかかる業務のひとつですが、AIを使うと構成から文章まで劇的に速くなります。

提案書の骨格作成（Claude推奨）

プロンプト例（Claude）：

「以下の商談メモをもとに、BtoB提案書の構成と各セクションのドラフトを作成してください。

【商談メモ】
顧客名：[企業名]
担当者：[役職・名前]
確認できた課題：
・[課題1]
・[課題2]
提案したいサービス：[サービス名]
想定予算感：[金額]

【提案書の構成】
1. 現状認識（顧客の課題を言語化）
2. 課題を放置した場合のリスク
3. 弊社の解決策
4. 導入事例（フィクションで構成例を作成）
5. 費用・スケジュール・サポート体制
6. ROI試算（概算でOK）
7. 次のステップ

各セクションを500字程度でドラフトしてください。」

ROI（費用対効果）の試算文章（ChatGPT推奨）

プロンプト例（ChatGPT）：

「以下の条件でROI（投資対効果）の試算文を、提案書に使える形で作成してください。

・導入コスト：月額[金額]円（年間[金額]円）
・削減できる工数：月[X]時間
・対象人数：[Y]名
・時給換算：[Z]円/時間
・その他の効果：[翻訳コスト削減など]

経営者が『導入を決断できる』レベルの説得力で、
数字を具体的に示しながら200〜300字でまとめてください。」

フェーズ③：メール・フォローアップ文章（所要時間：30分→5分）

営業メールは毎日大量に書きます。AIを使えば、状況に応じた最適な文章を数分で生成できます。

商談後の御礼メール（ChatGPT推奨）

プロンプト例（ChatGPT）：

「今日の商談後の御礼メールを作成してください。

・相手：[会社名] [役職] [名前]様
・商談の内容：[テーマ・議題]
・確認できた課題：[課題内容]
・次のアクション：[日程調整 / 提案書送付など]
・トーン：丁寧だが堅すぎない、温かみのある文体

300字以内でお願いします。」

失注後の関係維持メール

プロンプト例（Claude）：

「競合他社に失注した後、今後も良い関係を保つための
お礼・関係維持メールを作成してください。

・失注理由（分かっている範囲）：[価格 / 機能 / タイミング]
・今後つなぎ止めたいポイント：[半年後に再提案したい]
・トーン：押しつけがましくない。誠実で前向き。

相手が『この営業マンとは今後も話したい』と思えるような文章にしてください。」

フェーズ④：顧客分析・案件管理（月次レビューに使う）

担当顧客の優先順位付け（Claude推奨）

プロンプト例（Claude）：

「私の担当顧客リストを分析して、今月注力すべき顧客の優先順位を付けてください。

【顧客リスト（コピペ）】
A社：最終商談3ヶ月前、提案書提出済み、返答待ち
B社：先週商談、課題確認済み、次回提案予定
C社：6ヶ月未商談、昨年100万円の取引実績あり
D社：今月新規開拓、担当者の関心は高い

【判断軸】
・受注確度
・金額規模
・関係性の温度感
・タイムライン

優先順位と、各顧客への今週のアクション提案をください。」

失注分析・改善提案（Claude推奨）

プロンプト例（Claude）：

「以下の失注案件を分析して、改善提案をください。

・顧客：[企業名]
・提案内容：[サービス名・金額]
・失注理由（顧客からの説明）：[価格が高い / 他社が安かった]
・商談の経緯：[初回→2回目→提案→失注のざっくりした流れ]

1. 真の失注原因の仮説（表面的な理由の裏にあるもの）
2. 商談プロセスで改善できた点
3. 次回この顧客に再アプローチするタイミングと切り口
4. 同様の案件で勝率を上げるための提案書改善点」

フェーズ⑤：商談中のリアルタイム活用

商談中にAIを使うことにはまだ抵抗感を持つ人も多いですが、準備段階の活用が充実していれば商談中は人間力に集中できます。ただし以下の使い方は会議中でも有効です。

  • 議事録のリアルタイム文字起こし：NotionAI・Otter.ai・Notta等を使い、商談の会話を自動文字起こし
  • 商談直後の要約・アクション整理：文字起こしをClaudeに貼り付けて「要点と宿題を整理して」と依頼
  • その場でわからなかったことの即調査：顧客が言及した業界用語・競合製品をGeminiで即確認

AIを使う営業が「やってはいけない」3つのこと

NG行為なぜダメか正しい使い方
AIが書いた文章をそのまま送る「誰にでも送っている感」が出て信頼を損なう必ず自分の言葉で書き直し・加筆する
顧客の個人情報をAIに貼り付ける情報漏洩リスク・GDPR/個人情報保護法違反の恐れ個人を特定する情報は匿名化してから入力する
AIの出力を事実確認なしに使うハルシネーション（嘘の情報）が混ざる場合がある数字・社名・日付は必ず一次ソースで確認する

1週間「営業AI活用」チャレンジ

  1. 月曜：翌日の商談準備をGeminiで顧客リサーチ（30分→10分）
  2. 火曜：商談後の御礼メールをChatGPTで下書き→加筆送信（20分→5分）
  3. 水曜：提案書の骨格をClaudeで作成→中身を自分で肉付け（半日→2時間）
  4. 木曜：担当顧客リストをClaudeで分析・優先順位付け（1時間→15分）
  5. 金曜：今週の失注・懸念案件をClaudeに分析させ、来週の改善アクションを決める

5日間実践するだけで、1週間の「準備・文章・分析」にかかる時間が平均40〜50%削減できます。その時間を、顧客との対話・関係構築・新規開拓に再投資してください。それが「AIを使う営業」の本当の価値です。
